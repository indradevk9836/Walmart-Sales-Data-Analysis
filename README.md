# 🛒 Walmart Sales Analysis (Python + SQL)

An end-to-end retail sales analytics project using **Python** and **PostgreSQL** to clean, analyze, and extract business insights from Walmart sales data.

---

# 📌 Project Summary
This project analyzes Walmart sales data using Python and SQL to generate actionable business insights. The workflow includes data preprocessing, exploratory data analysis, and advanced SQL queries to evaluate sales trends, customer behavior, branch performance, product profitability, and payment methods. 

---

# 🎯 Key Objectives

- Clean and preprocess Walmart sales data using Python.
- Perform exploratory data analysis (EDA).
- Load cleaned data into MySQL and PostgreSQL.
- Solve business problems using SQL.
- Generate actionable business insights from sales data.

---

# 📊 Key Insights

- Identified top-performing branches and product categories.
- Analyzed sales trends across cities and time periods.
- Evaluated payment method preferences and customer ratings.
- Compared profitability across branches and product lines.
- Discovered peak shopping hours and purchasing patterns.
